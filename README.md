Workflow sandbox
===

A sandbox repo for trying out the workflows generated by gh-profiler.

If you open an issue on this repo, you'll see the two kinds of comments a gh-profiler Action can write to every new PR or issue in a project:

- It can write the concise profiler output as a comment on each new PR/issue, with a link to the full profile output in the Action log. ([Example](https://github.com/ehmatthes/workflow_sandbox/issues/15))
- It can write just the link to the Action log containing the profiler ouput. ([Example](https://github.com/ehmatthes/workflow_sandbox/issues/16))

Try it out!
---

Feel free to [open an issue](https://github.com/ehmatthes/workflow_sandbox/issues/new), look at the profiler output, and then close the issue. You'll see two comments, one in each style. Some maintainers want to see the concise output in a comment, while others don't want that information displayed quite so publicly.

If you're considering using the link-only workflow, keep in mind that Actions logs are visible to public (authenticated) users as well.

Generate your own workflow
---

To generate a gh-profiler workflow for your project, see the [GitHub Actions](https://github.com/ehmatthes/gh-profiler#github-actions) section of the gh-profiler documentation.
